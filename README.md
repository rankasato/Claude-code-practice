# はじめてのウェブページ

HTML・CSS・JavaScriptだけで作られた、初心者向けのシンプルなウェブページです。

## ファイル構成

- `index.html` — ページの中身(構造)。文章やボタンなどを配置しています。
- `style.css` — ページの見た目(色やレイアウトなど)を整えています。
- `README.md` — このファイル。プロジェクトの説明です。

## 見かた

`index.html` をブラウザ(Chrome、Safariなど)で開くだけで表示されます。サーバーの準備は不要です。

1. `index.html` をダブルクリックして開く
2. 「クリックしてね」ボタンを押すと、メッセージが表示される
